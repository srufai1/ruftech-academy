1. Write the type for "a number, ABS or blank", and a function that says which one it got.
2. Work out by hand: 9, 10.5, 15, 12 and exam 47/100. Then check with `calculateTotal`.
3. Explain to a teacher why an empty box and a 0 print differently.
4. Cause a `tsc` error on purpose. Read it aloud and explain each part.

**You have mastered this unit when** you did all four without help. If not, redo the guided
example tomorrow, not today, and try again.
