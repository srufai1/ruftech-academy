Unit 2.2 · Sorting and rankingAB
Step 1 · Lesson · about 25 min

Ties share a position

In simple wordsThree children run a race. Two cross the line together, so both are first. Nobody is second, because two people are already ahead of the next runner. That runner is third.

The technical way. This is called competition ranking. A pupil's position is 1 + the number of pupils with a strictly higher total.

School rule · GPIS decision D-02Pupils with the same total share a position, and the next position is skipped: 90, 90, 80 → 1st, 1st, 3rd.

Module 2 · Unit 2.2 · Arrays, objects and sorting

Ties share a position

When two pupils have the same total, they get the same position. The next position is skipped, so the count of pupils ahead stays true. This is how every GPIS report card prints a position.

GPIS D-02Standard competition ranking. 75, 70, 70, 65 gives 1, 2, 2, 4. Not dense ranking.
competitionRanks([75, 70, 70, 65]) // → [1, 2, 2, 4]

Rank inside one class at a time (D-03). A pupil with a missing subject is still ranked: the missing subject adds nothing (Q-07).
